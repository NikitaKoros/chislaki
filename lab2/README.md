# Численные методы решения уравнений

Приложение для решения уравнения `x * log10(x + 3) + (x + 1)^2 - 5 = 0` пятью численными методами.

## Установка и запуск

1. Убедитесь, что у вас установлен Go (версия 1.21 или выше)
2. Перейдите в директорию проекта:
   ```bash
   cd lab2
   ```
3. Установите зависимости:
   ```bash
   go mod tidy
   ```
4. Запустите приложение:
   ```bash
   # Базовая версия без графика
   go run task1/task1.go
   
   # Версия с графиком функции
   go run task1/task1_with_plot.go
   ```

## Функциональность

### Численные методы:
1. **Метод простой итерации** - требует начальное приближение x₀
2. **Метод Ньютона** - требует начальное приближение x₀
3. **Метод секущих** - требует два начальных приближения x₀ и x₁
4. **Метод хорд** - требует отрезок [a, b] с разными знаками функции
5. **Метод дихотомии** - требует отрезок [a, b] с разными знаками функции

### Интерфейс:
- Поле ввода точности ε (по умолчанию 0.0001)
- Кнопка "Очистить результаты"
- Для каждого метода: поля ввода параметров, кнопка "Найти решение" и область вывода результатов

### Результаты включают:
- Найденный корень
- Количество итераций
- Проверку условий сходимости

## Уравнение

f(x) = x * log₁₀(x + 3) + (x + 1)² - 5 = 0

Область определения: x > -3

## Примерные корни

Уравнение имеет корни приблизительно в точках:
- x ≈ -2.7 (отрицательный корень)
- x ≈ 1.3 (положительный корень)

## Рекомендуемые начальные приближения

- Для методов с одним начальным приближением: x₀ = 1.0 или x₀ = -2.5
- Для метода секущих: x₀ = 1.0, x₁ = 1.5
- Для методов с отрезком: [a, b] = [-3.0, -1.0] или [0.5, 2.0]
